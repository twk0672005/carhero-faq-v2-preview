# CarHero FAQ V2 Preview

這是 CarHero V2 的獨立公開預覽套件，直接由已驗證的 V1 runtime 分支而來。

- 預覽網站：https://twk0672005.github.io/carhero-faq-v2-preview/
- V2 source branch：https://github.com/twk0672005/carhero-faq-v1-update/tree/v2
- Source revision：`7d64ce1b0bd1cebc51aeab1bab93a6cf9385ddf0`
- Runtime：純靜態 HTML、CSS、JavaScript

## 版本邊界

V2 保留 V1 的首頁結構、FAQ 搜尋／分類／accordion、mobile menu、no-JS fallback、responsive 與 reduced-motion 行為。視覺由原站格式 `v2.css` 加上可回退的 Light palette `v2-light.css` 組成。

主品牌三色：暖米白 `#F6F1E7`、深墨黑 `#181816`、救援紅 `#D7192D`。WhatsApp 綠 `#087A43` 只作平台功能色。

這個 repo 只用作 V2 獨立公開預覽；沒有取代 V1，也不代表已獲批准合併或成為正式網站。

## 本機預覽

```bash
python3 -m http.server 4173
```

打開 `http://127.0.0.1:4173/`。
